Neuron Diagram Maker

Tools

Export as LaTeX (TikZ)

Copy this and paste it into your .tex file exactly where the diagram should appear. Your document needs the line \usepackage{tikz} once, in the preamble (the part above \begin{document}). Nothing else is required.

“Size” scales the drawing; labels stay the size of your document’s text, so long labels may not fit inside small neurons. “Complete test document” gives a whole file you can paste into a blank Overleaf project to check the picture compiles.

Export as an image

For Word or Google Docs: press Copy image and then paste into your document, or download the file and use Insert → Picture/Image. You can resize it in the document by dragging a corner.

How to use Neuron Diagram Maker

Drawing

  • Neurons: pick Firing neuron (gray) or Non-firing neuron (white), then tap or click on the canvas.
  • Connections: pick Stimulates (arrow), Inhibits (line ending in a dot) or Plain line, then drag from one neuron to another. You can also tap the first neuron, then tap the second.
  • Text: pick Text and tap where it should go (handy for time labels like t_1, t_2).
  • Moving: drag any neuron or text. Drag a connection sideways to curve it.
  • Moving around the page: drag on empty space. Pinch (iPad / trackpad) or use the + / − buttons to zoom.

Changing how things look

  • Select something (with the Select tool, or just tap it) and use the panel on the right: label, shading, border (e.g. thick for a “stubborn” neuron), size, arrow type, dashed lines, curve…
  • To change several neurons at once, hold Shift while clicking them, or use Select all.
  • Labels: type c, e, c_1 (subscript), c', \alpha… They are set in italics like LaTeX math. Untick “math” for ordinary text.

Getting it into your paper

  • LaTeX: Export LaTeX → Copy code → paste into your .tex file. Add \usepackage{tikz} to the preamble once.
  • Word / Google Docs: Export image → Copy image → paste. Or download the PNG and insert it.

Saving

  • Your current diagram is remembered automatically in this browser.
  • To keep several diagrams, use Save… to store each as a file, and Open… to edit it later.
